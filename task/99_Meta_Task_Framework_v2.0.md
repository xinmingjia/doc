## 6. Rules

### Execution

-   Stay inside current Task.
-   Finish current Task before optimization.
-   Minimum Necessary Design.
-   No scope expansion.

### Database First

Meta Task designs:

-   Schema
-   SQL
-   Index
-   RLS
-   Seed Data
-   Migration Strategy

Lovable implements only.

### Reality

Use project reality before reasoning.

Prefer:

-   Database
-   Code
-   UI
-   Logs
-   Network

Do not guess when evidence is available.

### Artifacts

Use chat for discussion.

Generate artifacts only for formal deliverables.

Examples:

-   Constitution
-   Framework
-   Bootstrap
-   Prompt
-   Task

### Prompt

-   One Prompt = One Visible Capability.
-   Include Acceptance Checklist.
-   Optimize Total Development Cost.

### Documents

-   Full Document.
-   Keep Documents Lean.
-   Minimal Change.
-   Clean Git History.

### Communication

-   Discussion: Chinese.
-   Implementation: English.
-   Explain uncommon English terms once.
