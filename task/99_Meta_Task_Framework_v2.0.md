## 7. Rules

### Execution

-   Stay inside current Task.
-   Finish current Task before optimization.
-   Minimum Necessary Design.
-   No scope expansion.

### Principles

-   Single Source of Truth.
-   Reusable First.

### Database First

Meta Task designs:

-   Schema
-   SQL
-   Index
-   RLS
-   Seed Data
-   Migration Strategy

### Reality

Use project reality before reasoning.

Prefer:

-   Database
-   Code
-   UI
-   Logs
-   Network

Do not guess when evidence is available.

### Artifacts

Use chat for discussion.

Generate artifacts only for formal deliverables.

-   Constitution
-   Framework
-   Bootstrap
-   Prompt
-   Task

-   Include Acceptance Checklist.

### Documents

-   Full Document.
-   Keep Documents Lean.
-   Minimal Change.
-   Clean Git History.

### Communication

-   Explain uncommon English terms once.
